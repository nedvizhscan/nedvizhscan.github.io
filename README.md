# Справочник ЗОУИТ, СЗЗ и ЗСО

Статический справочник по видамдам и кодам зон с особыми условиями использования территорий, санитарно-защитным зонам и зонам санитарной охраны источников водоснабжения.

Автор: Кирилл Крылов, основатель сервиса [НедвижСкан](https://nedvizhscan.ru/).

Сайт рассчитан на GitHub Pages репозитория `kiruxa-coder.github.io` и будет открываться по адресу https://kiruxa-coder.github.io/. Публичный репозиторий: https://github.com/kiruxa-coder/kiruxa-coder.github.io

## Страницы

- `index.html` — обзор ЗОУИТ, таблицы СЗЗ, ЗСО, ЛЭП, водоохранных зон
- `zouit.html` — виды и коды по ст. 105 ЗК РФ
- `szz.html` — санитарно-защитные зоны
- `zso.html` — пояса зоны санитарной охраны

Материал справочный и не заменяет выписку ЕГРН, ГПЗУ или решение об установлении конкретной зоны. Нормы сверены 25 ноября 2026 года.

Проверка конкретного участка: [https://nedvizhscan.ru/](https://nedvizhscan.ru/).
